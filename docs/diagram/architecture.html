How Clearlease works

Gemma 4 reads. Our code verifies every quote and decides every verdict. Clearlease never stores your text or photos.

Your browser
1

Paste or snap

A listing, a landlord's message or a lease photo. Phone numbers, emails and long ID numbers are removed and photos shrunk on your device.

2

API

POST /api/check with rate limiting and size and type checks.

3

Gemma 4 reads

gemma-4-26b-a4b-it turns text and images into JSON facts, each with its exact quote. Input is wrapped as untrusted data.

4

Verify

Schema check, then every quote is matched against the input. Anything not found is dropped.

5

Rules decide

TypeScript sets every verdict: price, 9 FTC scam signs and state lease law. The model never does.

6

Report

Three verdicts, quoted evidence, what Gemma read, questions to ask and help links, in English or Spanish.

Data the rules use

  • HUD Fair Market Rents (live, saved FY2027 fallback)
  • Census ACS median rent by ZIP
  • VA, DC and MD lease rules with statute links
  • FTC rental-scam warning signs

Google Cloud, us-east4

  • Cloud Run, scales to zero
  • Secret Manager holds the API keys
  • Firestore keeps anonymous scam-flag counts (one-way fingerprints, only when someone flags)
  • Cloud Build and Artifact Registry for deploys

Privacy and reliability

  • No accounts. Clearlease never stores or logs your text or photos
  • Checks are processed by Google's Gemini API
  • Photo location data stripped before upload
  • If Gemma doesn't answer, typed text gets a labelled keyword check and samples show a labelled saved result
  • Area map (Google Maps) is optional and decorative

Open weights

  • Gemma 4 is Apache 2.0
  • Self-host with Ollama: GEMMA_PROVIDER=ollama
  • Same prompt, quote checks and rules, so documents can stay on your own machine
